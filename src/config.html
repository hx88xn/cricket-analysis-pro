Configuration

Manage capture paths, database location, and camera preferences for the desktop workspace.

Save dialog will start in this folder when you end a capture.

Open an existing .sqlite file (e.g. one sent by a colleague), start a fresh blank database, or export a safe copy of the current one to hand off. Clear all data empties the current database in place (removes all teams, players, matches, etc. — keeps only the option lists). Opening, creating, or clearing a database reloads the app.

Refreshing may request camera permission once so device names can be resolved.
